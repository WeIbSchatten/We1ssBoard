Open **Appearance** with the palette button in the sidebar. Every
choice applies at once and is saved in the browser, so each admin and each
device keeps its own look. For changes beyond these options, use
[Custom CSS](/docs/operations/custom-css).

## Style

| Style | Look | Default background |
| --- | --- | --- |
| **Monochrome** | Ink and paper, nothing extra | Relief |
| **Pastel** | Lemon, pink, lilac and navy | Sakura |
| **Ocean** | Clear blue accent on cool graphite | Waves |
| **Emerald** | Fresh green accent on deep graphite | Network |
| **Obsidian** | Black glass and chrome headings | Stars |
| **Energy** | Colours of energy-drink cans, in series | Can |

**Energy** adds a **Series** choice: Classic, Sugarfree, Winter, Coconut,
Tropical and Red Edition.

## Theme

**Light**, **Dark** or **AMOLED black**. AMOLED uses pure black backgrounds,
which saves power on OLED screens.

## Background

Pick a drawing behind the pages: Plain, Relief, Waves, Mountains, Sakura,
Stars, Ribbons, Network, Track or Can. Any drawing works with any style.

**Background opacity** fades the drawing: 0% shows it as designed, 90% leaves
a hint of it. Each style remembers its own background and opacity.

## Interface size

Scales the whole panel: **Auto**, 90%, 100%, 110%, 125% or 150%. Auto picks a
size for the screen width and shows which one it chose.
